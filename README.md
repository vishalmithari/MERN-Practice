# MERN-Practice

Collection of MERN stack learning projects, web development practice, and JavaScript exercises.

## 📂 Repository Structure

| Folder / Project | Description |
| :--- | :--- |
| **`css1`** | React project practicing responsive CSS styling and layouts. |
| **`css2`** | React project practicing modern CSS and interface styling. |
| **`dypcet-cse`** | DYPCET Computer Science & Engineering department showcase app. |
| **`dypcet_cse_portal`** | React-based portal application for DYPCET CSE. |
| **`ExpressJS`** | Express.js backend exercises covering routing, middleware, and request handling. |
| **`FileSystem`** | Node.js File System (`fs`) module operations and server handling. |
| **`Module`** | Core Node.js modules practice (OS, Path, DNS, Net, Streams, Zlib compression). |
| **`mui_components`** | Material UI (MUI) components integration and practice with React. |
| **`mui_components1`** | Material UI practice project 1. |
| **`mui_components2`** | Material UI practice project 2. |
| **`mui_components3`** | Material UI practice project 3. |
| **`myapp`** | Interactive React application with controlled form inputs and state management. |
| **`NodeApp`** | Node.js asynchronous and synchronous execution patterns. |
| **`NOTES`** | Comprehensive lecture notes and presentations on Node.js, Express.js, and React.js. |
| **`server.js`** | Root Express.js server entry point. |

## 🚀 Getting Started

To run any of the React applications or Node services:

```bash
# Navigate to the specific project directory
cd <project-folder>

# Install dependencies
npm install

# Start development server
npm start
```
